# ============================================
# PRODUCTION-SPECIFIC SETTINGS
# ============================================
# When deploying to production, make sure to:
# 
# 1. Change all secrets/keys to strong random values
# 2. Set SMS_THROW_ON_FAILURE=true
# 3. Set NODE_ENV=production and APP_STAGE=prod
# 4. Use Neon pooled connection with sslmode=require
# 5. Configure Upstash Redis with rediss:// URL
# 6. Use strong BCRYPT_SALT_ROUNDS (12+)
# 7. Ensure the app runs as a long-lived process so APP.JOB crons fire
# 8. Review and adjust rate limits based on traffic

# ============================================
# SECURITY BEST PRACTICES
# ============================================
# 
# ✅ Never commit .env file to version control
# ✅ Use different secrets for dev/staging/production
# ✅ Rotate secrets periodically
# ✅ Use strong random values for JWT secrets (at least 32 characters)
# ✅ Keep SMS API keys secure
# ✅ Monitor failed login attempts
# ✅ Review rate limiting logs regularly
# ✅ Set up alerts for suspicious activity
# ✅ Use HTTPS in production
# ✅ Enable database SSL in production
# ✅ Regular security audits
